
# 🚛 KJA Dispatching

A responsive business website developed for KJA Dispatching, a freight dispatching service focused on helping owner-operators keep their trucks moving and maximize their business opportunities.

🌐 **Live Website:** https://www.kjadispatching.com

## 📖 About the Project

KJA Dispatching is a real-world web development project designed to provide a professional online presence for a freight dispatching business.

The website allows prospective clients to learn about available services, submit driver applications, and contact the business directly.

## ✨ Features

- Responsive layout for desktop and mobile devices
- Professional navigation and branded design
- Freight dispatching service information
- Online driver application form
- Business contact form
- Netlify Forms integration
- Custom submission confirmation page
- Basic spam protection using honeypot fields

## 🛠️ Technologies Used

- **HTML5** - Website structure and semantic markup
- **CSS3** - Styling and responsive layouts
- **Netlify** - Website hosting and form processing
- **Git & GitHub** - Version control and source code management

## 🚀 Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/JMHDev313/KJA-Dispatching.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

**Note:** Netlify Forms requires a Netlify deployment to process submissions. Opening the HTML file locally will not provide the complete form-processing functionality.

## 🔐 Security Considerations

The website uses Netlify's hosted form-processing functionality and includes honeypot fields to help reduce automated spam.

Honeypot fields are not a complete defense against malicious submissions. Additional spam filtering and validation may be appropriate as the website grows.
